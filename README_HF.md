# Neural Image Captioning Research Platform (ViT-B/16 + Cross-Attention)

A deep learning vision-language research system implementing and comparing three distinct architectures on the Flickr8k benchmark:
1. **Show and Tell (CNN-LSTM Baseline)**
2. **Adaptive Spatial Attention with Visual Sentinel Gating**
3. **Vision Transformer (ViT-B/16) + Multi-Head Cross-Attention Decoder**
